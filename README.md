# Munezia VPN — стартовый манифест

Здесь лежит один файл: `bootstrap.jws`.

Это подписанный документ, из которого приложение Munezia VPN узнаёт адрес своего сервера. Подпись — Ed25519;
открытые ключи зашиты в приложение, поэтому подменённый или подделанный файл оно отвергнет. Отсюда следует, что
этому хостингу не нужно доверять — от него требуется только быть доступным.

Второе место выкладки — https://munezia.com/bootstrap.jws. Файлы в обоих местах одинаковы побайтно.

Сайт продукта: https://munezia.com
